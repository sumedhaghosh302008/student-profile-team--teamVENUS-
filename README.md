## 📂 Repository File Structure

The project directory consists of modular HTML files styled with a unified cascading stylesheet layout [image_NsEebV.png]:
* `venus.html` — The main showcase landing dashboard displaying team profile cards [image_NsEebV.png].
* `profile.html` — Individual professional developer layout page [image_NsEebV.png].
* `skills.html` — Technical competencies mapping core skills (Java, Python, HTML, CSS, Problem Solving), soft skills, and academic interests (AI, ML, Web Development) [image_pVdi2V.png].
* `contact.html` — Communication portal containing direct team contact nodes [image_Q_KluJ.png].
* `style.css` — Core responsive grid layout engine utilizing custom linear gradients (`#0f172a` to `#1e293b`) and automatic element wrapping configurations [image_tWSCSI.png].

---

## 🛠️ Tech Stack & Concepts Applied

* **Markup & Structure:** Semantic HTML5 layout architecture [image_NsEebV.png].
* **Design & Layout Engine:** CSS3 Grid (`repeat(auto-fit, minmax(240px, 1fr))`) and Flexbox layouts for fully responsive user experiences across mobile and desktop environments [image_tWSCSI.png].
* **Collaboration & Workflows:** Git feature branching workflows (`feature/*`), collaborative peer pull requests, and automated testing deployments through GitHub Pages.
